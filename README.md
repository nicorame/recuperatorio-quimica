# Guía de recuperatorio · Química General (UTN-FRC)

Guía de estudio para el recuperatorio del 2º y 3º parcial de Química General (Ingeniería Industrial).

**Ver online:** https://nicorame.github.io/recuperatorio-quimica/

Incluye conceptos cortos, diagramas, la receta para cada tipo de ejercicio que se repite en los simulacros, ejercicios resueltos, banco de Verdadero/Falso y un formulario de una página.

- 🔵 2º parcial: fuerzas intermoleculares y líquidos, sólidos, gases, soluciones, termoquímica (Hess), espontaneidad, cinética.
- 🟠 3º parcial: equilibrio químico, pH, Kps, redox (ion-electrón), pilas y electrólisis, corrosión.

También disponible en [PDF](Guia_Quimica_Recuperatorio.pdf).
